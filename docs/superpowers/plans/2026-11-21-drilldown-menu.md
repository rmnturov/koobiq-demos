# Drilldown Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Добавить в каталог демку отдельного составного меню с переходами между экранами, плавным изменением размеров и готовым настраиваемым блоком автообновления.

**Architecture:** Локальный компонент владеет одним CDK Overlay и стеком экранов, заданных Angular-шаблонами. Список переиспользует пункты Koobiq и FocusKeyManager, а прокрутка — KbqScrollbarViewport. Автообновление подключается как отдельный готовый блок и хранит значение у потребителя; навигация не зависит от параметров таблицы.

**Tech Stack:** Установленные Angular 21, Angular CDK 21, Koobiq 21.1, signals, standalone-компоненты, SCSS, Vitest и Angular TestBed.

**Spec:** [Согласованный проект](../specs/2026-11-21-drilldown-menu-design.md).

Статус: этапы 1–7 выполнены, независимое ревью проведено, десять замечаний исправлены. [Результат ревью](../reviews/2026-11-21-drilldown-menu-review.md). Целевые проверки 32/32; полный прогон 736 успешных и четыре исходных сбоя timepicker-compare.

## Global Constraints

- Работа идет в существующей ветке `feat/drilldown-menu-demo`; новый worktree не требуется.
- Максимальная высота всей панели по умолчанию — **480 px**, включая шапку.
- Шапка остается неподвижной при прокрутке. Прокручивается только содержимое текущего экрана.
- Используется **KbqScrollbarViewport** из `@koobiq/components/scrollbar`.
- Согласованная последовательность Tab: доступные действия шапки в порядке их отображения, затем список как одна остановка.
- Esc внутри раздела возвращает на уровень выше; в корне закрывает панель.
- Начальная ширина — 320 px, длительность перехода — 200 мс; размеры ограничиваются доступным местом в окне.
- Период задается в миллисекундах; `null` означает отключенное обновление. Пресеты: 15 с, 30 с, 1 мин, 5 мин, 10 мин, 30 мин; начальное значение и сброс — 5 мин.
- Цвета, типографика, скругления и тени берутся из Koobiq; текст и иконки при переходе не масштабируются.
- В первой версии работает только вложенный раздел **Автоматическое обновление**; остальные внутренние разделы не реализуются.
- Никаких новых зависимостей, глобальных стилей, ShadowDom и изменений установленного пакета Koobiq.
- Существующие изменения `package.json`, `package-lock.json`, `src/app/app.config.ts` не входят в коммиты этой работы. Все команды git add перечисляют файлы явно.
- Проверки состояния и фокуса автоматизируются; плавность движения, геометрия и реальный Tab проверяются в браузере. В jsdom эти свойства не считаются проверенными.

## Review Focus

- Родительский экран содержит готовый блок или поле со своим состоянием: переход не уничтожает их, возвращение восстанавливает состояние; тест задачи 2.
- Пункты меняются, исчезают или становятся недоступными: у списка остается ровно одна доступная остановка Tab либо безопасная цель для пустого списка; тест задачи 1.
- Из пользовательского вложенного оверлея приходит уже обработанный Esc: внешний экран не меняется; тест задачи 3.
- Переход разворачивается или меню закрывается до завершения движения: устаревшее завершение не скрывает текущий экран и не крадет фокус; тест задачи 4.
- Текущее значение не входит в пресеты, а пресеты меняются во время работы: значение сохраняется, ложная галочка не появляется; тест задачи 5.

## Task 5. Готовый блок автообновления

**Files:** создать `auto-refresh/auto-refresh-menu.ts`, `.html`, `.scss`, `.spec.ts`.

## Основания технических решений

Пути сверены с текущим репозиторием: `angular.json` использует `@angular/build:unit-test`; флаг include есть в установленной схеме builder. `src/test-setup.ts` содержит заглушку scrollTo для jsdom, но не реализует layout и нативное перемещение Tab.

В установленных `koobiq-components-dropdown.mjs` и `koobiq-components-select.mjs` используется KbqScrollbarViewport. KbqDropdownItem имеет необязательный parentDropdownPanel, собственный FocusMonitor, hover-focus и tabindex; эти особенности учитывает задача 1. CDK FocusKeyManager принимает signal списка и Injector, поэтому дополнительная копия клавиатурного менеджера не нужна.

Для измерений после рендера используется [afterNextRender](https://angular.dev/api/core/afterNextRender), для переходов — подход с [нативным CSS в Angular](https://angular.dev/guide/animations/css). Анимация width/height сознательно допускает layout: требование — плавная геометрия без растяжения содержимого, а не выполнение всех изменений только на GPU.
