# Markdown Heading Scale Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Подбирать стиль H1 под интерфейс и сравнивать производные H2–H6 в обеих колонках полигона.

**Architecture:** SCSS подготавливает постоянные коэффициенты двух шкал. Браузер рассчитывает типографику и интервалы в CSS. Angular передаёт значения контролов и обновляет подписи образцов.

**Tech Stack:** Angular 21, SCSS, CSS custom properties, CSS math functions, Vitest и браузерные проверки.

**Spec:** [Масштаб заголовков Markdown](../specs/2026-11-25-markdown-heading-scale-design.md)

## Global Constraints

- Ступени H1 — 18/26, 20/28, 24/32, 28/32, 36/44. Исходное положение использует отдельную шкалу каждой колонки.
- Поправка к отступу — от −4 до +4 px, шаг 1 px. Результаты расчётов — целые CSS-пиксели.
- Изменения ограничены Markdown-заголовками. Семантика H1–H6, основной текст и остальные блоки сохраняют прежние стили.

## Review Focus

Проверить раздельные исходные значения колонок, ограничение отступа при крайних положениях, применение переменных к одному экземпляру, актуальность подписей после сброса и доступность контролов при просмотре примеров на узком экране.
