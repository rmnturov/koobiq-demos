# Тестовый мультивыбор в параметрах таблицы

Статус — согласовано 23 ноября 2026 года.

## Назначение

Демо «Меню с переходами» показывает, как искать столбцы и выбирать несколько вариантов во вложенном экране. Пункт «Мультивыбор с поиском» находится в конце корневого меню «Параметры таблицы». Выбор работает на тестовых данных в рамках сеанса демо.

## Подход

- Экран в шаблоне демо использует существующую панель и переходы. Поиск, навигация по результатам, начальное состояние и тестовые данные определяются в демо. Пользователь выбрал этот вариант для одного тестового пункта.
- Отдельный компонент по образцу «Автоматического обновления» позволил бы передавать список столбцов и начальный выбор при повторном подключении. Для него потребовался бы отдельный API.

## Поведение

- При открытии фокус переходит в поле «Столбец». Поиск фильтрует названия по подстроке без учёта регистра и подсвечивает совпавшие фрагменты по макету. Пустые группы скрываются. Если совпадений нет, экран показывает «Ничего не найдено».
- В четырёх группах из макета показаны русскоязычные поля таблицы инцидентов информационной безопасности. Среди них «Идентификатор инцидента», «Дата обнаружения», «Критичность», «Состояние», «Адрес источника», «Дата закрытия». Запрос «дата» подходит для проверки подсветки в нескольких результатах.
- Нажатие на строку меняет отметку и оставляет экран открытым. Выбор сохраняется при изменении запроса, переходе назад и повторном открытии меню. Запрос сохраняется до закрытия меню.
- Шапка, поле поиска и действие «Сбросить по умолчанию» остаются видимыми при прокрутке списка. Сброс восстанавливает исходные отметки и очищает запрос.
- Поле и список работают как единый элемент с одной остановкой Tab. Порядок обхода — «Назад», поле поиска, «Сбросить по умолчанию». Фокус остаётся в поле, а ↑ и ↓ меняют активный результат и при необходимости прокручивают его в видимую часть списка. Enter переключает отметку активной строки. Пробел и остальные клавиши редактируют запрос обычным способом. Esc возвращает к открывшему экран пункту.
- Поле программно связано со списком и сообщает вспомогательным технологиям, какой результат активен. Список сообщает состояние выбора каждой строки. После фильтрации активная строка должна принадлежать видимым результатам. [WAI-ARIA Combobox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/), [WAI-ARIA Listbox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)

Название пункта, конкретные поля и поведение сброса предложены исполнителем. При проверке нужно пройти поиск и подсветку, выбор нескольких полей мышью и клавиатурой, порядок Tab, пустое состояние, сброс, возврат и повторное открытие меню.
