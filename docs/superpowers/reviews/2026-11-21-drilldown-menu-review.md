# Ревью меню с переходами

Независимый рецензент проверил ревизию `a67e3d2` относительно `30d91b5`, согласованный проект, план и установленные реализации Angular CDK и Koobiq. Проверка включала отдельный браузер Chrome. Рецензент не менял исходники и не участвовал в реализации.

Критических замечаний нет. Найдены десять существенных замечаний; все воспроизведены и исправлены в одном проходе. Повторное независимое ревью исправлений не проводилось: результат подтвержден регрессионными тестами и повторной проверкой в браузере. Отложенных замечаний нет.

| Замечание | Исправление и проверка |
| --- | --- |
| scrollIntoView прокручивает оболочку и скрывает видимое движение | FocusMonitor с preventScroll, раскрытие пункта только в KbqScrollbarViewport, overflow:clip. Регрессионный тест прокрутки предка; в браузере scrollLeft=0, видимая координата экрана 320 → 315 → 302 → 281 px |
| Неподвижная мышь меняет начальный фокус во время движения | Входящие mouseenter подавляются до фактического изменения координат указателя. Клик и клавиатура остаются доступны. Тест и проверка выбора Enter без движения мыши |
| Tab застревает на скрытом или отключенном поле | Совместная проверка isFocusable и isTabbable внутри панели и при выходе из портала. Тесты скрытого поля и недоступной кнопки |
| Скрытый текущий пункт сохраняет единственную остановку | Доступность учитывает реальную фокусируемость; неактивные экраны сохраняют свою позицию, скрытые пункты активного списка исключаются. Тест скрытой обертки |
| После заполнения пустого списка фокус остается на резервном контейнере | Восстановление доступных пунктов переводит фокус с контейнера на пункт. Тест отключения и повторного включения всех пунктов |
| Удаление промежуточного экрана оставляет его в истории | История очищается при удалении любого определения экрана. Тест root → middle → child с удалением middle |
| menu.open не присоединяет портал | Публичный метод использует тот же путь открытия, что и триггер. Тест программного открытия закрытой панели |
| Направление возврата зависит от наличия opener | Направление передается из операции со стеком. Тест back после navigate без opener |
| initialFocus игнорируется рядом со списком; неизвестный период получает старый фокус | Явная цель имеет приоритет. Если селектор периода не находит вариант, используется первый доступный, а не ранее посещенный. Тест формы со списком и повторного входа с неизвестным периодом |
| Удаление триггера теряет фокус | При уничтожении сфокусированной панели используется сохраненная доступная цель после триггера. Учтен порядок уничтожения портала Angular. Тест условного удаления кнопки |

Все десять сценариев наблюдались в падающем прогоне до исправлений. После исправлений проходят все 32 целевых теста. Финальный полный набор: 736 успешных тестов и четыре существующих сбоя timepicker-compare; все четыре отдельно воспроизведены на исходной ревизии с теми же зависимостями. Сборка проходит, четыре теста упаковщика проходят. Геометрия, прокрутка и клавиатура дополнительно проверены в браузере; отдельный скринридер не запускался.

В разделе Declined to judge рецензент указал только четыре исходных сбоя timepicker-compare. Они оставлены вне этой задачи, поскольку их воспроизведение на базовой версии подтверждено, а эти исходники и тесты ветка не меняет.

## Решения исполнителя

- Названия этапов в плане приведены к Task N для совместимости со скриптами учета. На поведение демки это не влияет.
- Tab внутри панели маршрутизируется явно с сохранением порядка доступных элементов. Это делает переход из портала предсказуемым; риск для сложных пользовательских контролов покрывается фильтрацией событий и проверками фокуса.
- Готовые дочерние блоки регистрируют настоящие пункты Koobiq в родительском списке: запросы Angular не пересекают границы компонентов. Пользовательский составной блок должен соблюдать этот контракт регистрации.
- Миксины оформления Koobiq подключены под селектором только этой панели с учетом проекции Angular. Это сохраняет готовые состояния пунктов; зависимость от Sass API Koobiq потребует проверки при обновлении библиотеки. Размер стилей дает предупреждение бюджета, сборку не останавливает.
- Четыре исходных сбоя оставлены вне изменений. Полный набор тестов остается с этими четырьмя сбоями; новые сценарии проходят.
