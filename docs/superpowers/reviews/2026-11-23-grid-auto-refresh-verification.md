# Проверка демо автообновления

Дата: 23 ноября 2026 г. Адрес: `/demo/grid-auto-refresh`.

Реализованы локальный случайный поток, отдельный контроллер обновления и интерфейс на публичных компонентах Koobiq. Бесконечная прокрутка добавляет блоки по 50 строк из примененного снимка; AG Grid виртуализирует видимые строки.

## Проверки

- Чистая установка `npm ci --no-audit --no-fund` успешна.
- 29 новых проверок модели, сервера, контроллера и фильтров проходят; вместе с 6 проверками реестра — 35.
- Полный набор: 739 успешных, 4 ошибки. Ошибки совпадают с исходной проверкой: три сценария вставки старого таймпикера в `old-field.spec.ts` и пустая маска в `panel.component.spec.ts`.
- Проверки скриптов: 4 успешных.
- Сборка успешна. Остаются предупреждения о бюджете начального пакета (1,96 МБ при пороге предупреждения 1 МБ), CommonJS в date-formatter и двух выражениях таймпикера.
- Браузер: автоматическое поступление, защищенный счетчик, неизвестное количество, ошибка и восстановление, явное обновление, сохранение карточки и сброс дальнего выделения, фильтр статуса, сортировка и открытие карточки клавишей Enter.
- Браузер: PageDown подгружает второй блок до 100 строк; одновременно в DOM было 39 строк. Шапка сохраняет положение.
- Браузер: Topbar и ActionsPanel переносят действия в «Ещё»; вложенная настройка и скрытое массовое действие работают. Светлая и темная темы проверены. Ошибок в консоли нет.
- При ширине рабочей области 746 px открытая панель оставляет списку 320 px, настройки доступны. Ниже 600 px карточка занимает рабочую область, список временно inert; закрытие возвращает список. Временные размеры браузера сброшены.

## Ревью и решения

Независимое ревью выявило три существенных замечания; все исправлены:

1. Возврат поиска к примененному значению до ответа теперь отменяет устаревшую выборку. Добавлена проверка с отложенным ответом.
2. Ответ начатой проверки после выключения или скрытия вкладки сохраняет обнаруженные записи без автоматической вставки. Добавлены обе проверки.
3. Клавиатурные обработчики публичного API AG Grid открывают карточку и запускают управляемую сортировку из фокуса ячейки/заголовка. Проверено в браузере; `aria-sort` восстанавливается после внутреннего обновления AG Grid.

Дополнительные вопросы ревью закрыты так:

- Тема использует старое объявление peer-зависимости tokens 3. Узкое npm override сохраняет tokens 4 приложения; чистая установка, сборка и обе темы проверены.
- Пакет темы публикует ESM с импортами без расширений. Только этот пакет включен в `server.deps.inline` Vitest; проверка загрузки реестра использует настоящий модуль.
- Постоянный тост размещен локально под шапкой: глобальный ToastService не предоставляет нужную привязку. Постоянная polite live-region монтируется пустой и получает текст при обнаружении записей; отсчет секунд не озвучивается. Проверка экранным диктором отдельно не проводилась.
- Попытка полной отрисовки Koobiq/AG Grid в jsdom встретила ошибку вычисления CSS specificity в jsdom. Интеракции компонентов проверены в настоящем браузере; регрессионные проверки асинхронного поведения выполняются без подмены компонентов.
- Настоящий транспорт, изменения/удаление инцидентов и гарантии серверной пагинации вне согласованного объема.
